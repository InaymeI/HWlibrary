# Windows Vista Aero — экспериментальная тема

Ветка `arena/200e0d0b-hwlibrary`, черновой PR #10. Не слита в `main`.

**Пуск / Настройки → Вид → Тема → Windows Vista Aero**

Либо `python -m mt --theme aero`. Внутренний ключ `aero` оставлен для
совместимости с сохранёнными настройками. Светлая и тёмная темы не удалены.

## Что изменилось

- Оригинальный фон Aurora (`Windows Vista/Desktop/img24.jpg`).
- Семь оригинальных Vista ICO из shell32.dll: папка, компьютер, поиск,
  сеть, справка, настройки и переключение окон.
- Тёмная стеклянная рамка и чёрно-зелёная глянцевая панель задач.
- Кнопки панели задач с подписями, как в Vista, вместо плиток Superbar Windows 7.
- Светлая рабочая область, зелёная командная полоса и глянцевые кнопки.
- Компактная типографика, строки дерева 28 px и навигация 30 px.
- При смене темы восстанавливаются прежние размеры и компоновка.

Это стилизация Qt, не системный DWM: размытия содержимого за окном нет.

## Шрифт Vista

Vista использовала **Segoe UI**. В теме он указан первым для всех обычных
элементов, затем идут Tahoma, Noto Sans и DejaVu Sans. Моноширинные поля
используют Consolas / DejaVu Sans Mono.

Точная версия Segoe UI из Vista — проприетарный файл Microsoft, в приложении
не распространяется. Если нужна именно старая версия, установите законно
полученный шрифт из Vista в ОС и перезапустите приложение. Современный Segoe UI
может отличаться от версии Vista. Если Segoe UI отсутствует, Qt выбирает
доступный запасной шрифт. В Linux-песочнице скриншоты сделаны с запасным шрифтом,
не с настоящим Vista Segoe UI.

## Источники и права

Ассеты загружены напрямую из
[bartekl1/windows-ui-assets](https://github.com/bartekl1/windows-ui-assets).
Точные пути и ревизия: `mt/assets/aero/sources.json`.
Файлы используются локально, без сетевых загрузок при запуске.

Графика Microsoft **не подпадает под MIT приложения**. См.
`mt/assets/aero/NOTICE.md`: архивное, учебное и личное использование;
права на распространение и коммерческое использование необходимо проверять
отдельно. DLL, исполняемые файлы и звуки не включены.
