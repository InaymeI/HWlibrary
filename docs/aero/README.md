# Frutiger Aero — экспериментальная тема

Изолированная работа в ветке `arena/200e0d0b-hwlibrary`. Не слита в `main`.

Включение: **Настройки / Пуск → Вид → Тема → Frutiger Aero (Windows 7)**.
Кнопка темы перебирает светлую, тёмную и Aero. Выбор сохраняется между запусками.
Прежние темы остаются доступными; данные SQLite и синхронизация не изменены.

- Оригинальные обои Windows 7; процедурный небесный фон только при отсутствии файла.
- Светлые стеклянные панели и глянцевые голубые кнопки.
- Нижняя панель задач вместо вертикальной навигации.
- Круглая кнопка «Пуск», меню приложения, статус синхронизации и часы.
- При смене темы расположение панели и строки состояния восстанавливается.

Это стилизация, а не системный Windows Aero: размытия содержимого за окном нет.
Рисование выполняется средствами Qt без внешних библиотек или сетевых ресурсов.

## Windows 7 assets (second iteration)

Оригинальные обои Windows 7 и семь объёмных ICO из
[bartekl1/windows-ui-assets](https://github.com/bartekl1/windows-ui-assets).
Пути и точная ревизия зафиксированы в `mt/assets/aero/sources.json`.
Графика Microsoft не подпадает под MIT приложения: см.
`mt/assets/aero/NOTICE.md` (архивное, учебное и личное использование;
права на распространение и коммерческое использование нужно проверять отдельно).

Добавлены фон Windows 7 с пропорциональным заполнением окна, цветные системные
иконки, узкая стеклянная рамка, голубая командная полоса в духе Проводника,
компактные прямоугольные карточки и увеличенные иконки панели задач.
Ассеты входят в пакет приложения, сетевые запросы для оформления не нужны.

## Типографика и плотность интерфейса

В Aero для всех элементов используется стек `Segoe UI → Tahoma → Noto Sans →
DejaVu Sans`. Segoe UI — стандартный интерфейсный шрифт Vista/7. На Windows с
установленным Segoe UI выбирается он; на Linux без него используется доступный
запасной шрифт. Файлы Microsoft-шрифтов не поставляются с приложением. При наличии
законно полученного Segoe UI установите его обычным способом в ОС и перезапустите
приложение. Скриншоты в песочнице сделаны с запасным шрифтом, не с Segoe UI.

Для менее «карточного» вида уменьшены заголовки, статистика и отступы, строки
дерева имеют высоту 28 px, навигация — 30 px. Выделение — тонкая голубая рамка с
радиусом 3 px без декоративной тени; основная область непрозрачная белая, как в
Проводнике. При возврате в прежние темы восстанавливаются их исходные отступы и
высота строк. Тему можно также запустить через `python -m mt --theme aero`.
